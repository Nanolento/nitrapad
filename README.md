Neot
====

The simple and fast text editor. Written in Python using ncurses (for now). Neot is in heavy development and is far from done.
Use at your own risk.

Usage
-----

Clone this repository and simply run this:

    $ python main.py <filename>

That's it, really.

Dev notice
----------

Before, this application has been called Nitrapad and was abandoned as a project after getting the most basic functionality in.
Now we are revamping the whole structure of the application and making the application very modular, allowing, in the future
for different frontends and perhaps even changing the language neot is written in without having to rewrite everything.
I am excited for this program's new direction.
